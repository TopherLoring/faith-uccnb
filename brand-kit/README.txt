LOGOS / UCC
  Official United Church of Christ files (comma, logo, "a just world for all").
  Follow the UCC rules on page 7 of the guide. Fresh copies: ucc.org.

FONTS
  Fraunces (headlines) and Instrument Sans (everything else). Free, SIL Open Font License.
  Install on Windows: select all the .ttf files, right-click, Install.
  Install on Mac: double-click each .ttf file, then Install Font.
  Install the fonts BEFORE opening the templates, then reopen Word/PowerPoint.
  If you can't install them, use Georgia for headlines and Arial for text.

TEMPLATES
  Sunday-Bulletin-Template.docx       Letter, landscape, prints both sides (flip on short edge), folds in half
  Event-Flyer-Template.docx           Letter, portrait
  Offering-Envelope-Template.docx     3.5 x 6.5 in (#6 3/4 envelope). Print one test first.
  Sunday-Projector-Slides.pptx        16:9 slides for Sunday worship
  Social-Media-Post-Templates.pptx    1080 x 1080 posts. File > Export > PNG to save a post.
  Replace anything in [blue brackets]. Swap photos with right-click > Change Picture.
  Save a dated copy each time; keep the original template clean.
